# PS2 Store for Playnite v1.0.0-beta.1

First public **beta** of the PS5-style PlayStation 2 store for Playnite fullscreen (PS5ish theme).

## Install
1. Download `BDSoftPS2Store_9411ebc2-4eeb-439b-84a2-ca7011456b22_1_0_0.pext` below.
2. Double-click it (or drag it onto Playnite), confirm, restart Playnite.
3. Click the "PS5ish teması bulundu" notification (or Extensions → BD Soft PS2 Store → PS5ish temasına entegre et) and restart Playnite.

Requires Playnite 10 and the PS5ish fullscreen theme. PCSX2 is needed to play linked games.

## What's in this beta
- PS2 catalog (~3,900 games) inside the theme's PlayStation Store page
- Search with abbreviations, favorites, on-this-PC icons
- Add to library, link your own game files to PCSX2
- "Kur" button with per-game `externalUrl` (games.json)
- Controller support, theme sounds, endless Discover row
- One-click theme integration with backup and restore
- Developer screen

## Known limitations
- UI is Turkish only.
- On the store page the controller only works while the Store tile is focused (theme limitation).

The store does not download games.
